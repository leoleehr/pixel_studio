A 主歌

敘述故事：旋律較低、歌詞較多，每次歌詞都不同。

B 副歌

說出重點：旋律最高、最好記憶，歌詞重複出現。

C 橋段

轉換方向：和弦與旋律換個方向，讓最後的副歌更有力量。

承段落的伴奏設計

主歌讓位給歌手，副歌釋放能量

段落任務建議伴奏
前奏告訴聽眾速度與調性四分音符下刷，或將副歌和弦彈奏一輪
主歌讓歌詞清楚傳達蹦洽拉、四分音符，音量小一點
導歌慢慢升溫8 Beats，越刷越密集
副歌全曲最高點切分或 16 Beats，刷滿六條琴弦
橋段製造對比更換刷法、加入停頓，或只彈和弦長音
尾奏收尾放慢速度，最後一個和弦刷奏一下，讓聲音完整延續

承移調夾 Capo

Capo：一個可以移動的上弦枕

  • 每往上夾一格，所有琴弦升高一個半音
  • 左手依照原本的和弦指型按壓，「Capo 當成第 0 格」
  • 夾在琴衍旁邊、和琴衍平行，聲音才乾淨
  • 和弦譜常寫「Capo 2，Play C」：夾在第 2 格、使用 C 指型，實際是 D 調

指型加上 Capo，等於實際的調

原講義的樂譜常見「Key: F　Play: C　Capo: 5」，意思是使用 C 指型、夾在第 5 格，彈出 F 調。

C → C# → D，升高兩個半音，因此夾在第 2 格。

樂譜寫著「Capo 3，Play G」，實際是哪一個調？

  1. A
  2. B
  3. Bb
  4. C
G → G# → A → Bb，升高三個半音，是 Bb 調。
