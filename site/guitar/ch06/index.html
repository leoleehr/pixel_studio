你選了哪一首？

  • 每人用一句話介紹期中曲目：為什麼選它

說重點：旋律最高、最好記，歌詞重複出現。

轉個彎：和弦與旋律換個方向，讓最後的副歌更有力。

承段落的伴奏設計

主歌讓位給歌手，副歌把能量放出來

段落任務建議伴奏
前奏告訴大家速度與調四分音符下刷，或副歌和弦彈一輪
主歌讓歌詞被聽清楚蹦洽拉、四分音符，音量小一點
導歌慢慢升溫8 Beats，越刷越密
副歌全曲最高點切分或 16 Beats，刷滿六條弦
橋段製造對比換刷法、停頓，或只彈和弦長音
尾奏收尾放慢，最後一個和弦刷一下讓它響完

承移調夾 Capo

Capo 就是一個可以移動的上弦枕

  • 每往上夾一格，所有弦升高一個半音
  • 左手照原本的和弦指型按，「Capo 當成第 0 格」
  • 夾在琴衍旁邊、和琴衍平行，聲音才乾淨
  • 和弦譜常寫「Capo 2，Play C」：夾第 2 格、用 C 指型，實際是 D 調

指型＋Capo ＝ 實際的調

原講義的譜上常見「Key: F　Play: C　Capo: 5」，意思就是用 C 指型、夾第 5 格，彈出 F 調。

C → C# → D，升兩個半音，所以夾第 2 格。

譜上寫「Capo 3，Play G」，實際是什麼調？

  1. A
  2. B
  3. Bb
  4. C
G → G# → A → Bb，升三個半音是 Bb 調。
