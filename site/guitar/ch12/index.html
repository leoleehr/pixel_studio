承00:20–00:55　第六章、轉調與移調 Transpose

移調：每個和弦移動相同的距離

原調 CCGAmFEmDm
升高 2 個半音 → DDABmGF#mEm
降低 3 個半音 → AAEF#mDC#mBm
以級數觀察IVviIViiiii

兩種方法

① 更換和弦：每個和弦都移動相同的半音數。② 使用 Capo：指型維持不變，夾高幾格就升高幾個半音。

級數最實用

記住歌曲是 I–V–vi–IV，換到任何調都能立刻排出和弦。

互動選擇題
承小測驗

移調練習

G → D → Em → C 移到 C 調（降低 7 個半音，或升高 5 個半音），會是哪一組和弦？

  1. C → F → Dm → Bb
  2. C → G → Am → F
  3. C → G → Em → F
  4. A → E → F#m → D
G 調的 I–V–vi–IV，換到 C 調仍是 I–V–vi–IV：C → G → Am → F。

歌曲是 E 調，你想使用 C 指型，Capo 要夾在第幾格？

  1. 第 4 格
  2. 第 3 格
  3. 第 5 格
  4. 不需要夾
C → C# → D → D# → E，相差四個半音，夾在第 4 格。也可以改用 G 指型夾在第 9 格，只是位置太高。
承二、歌曲定調之方法 Make Your Own Key

四個步驟，算出你的調

1

找出歌曲的最高音

通常位於副歌，對照原唱或樂譜。

2

測出自己的最高音

能輕鬆演唱、無需用力的最高音，避免以極限音為準。

3

計算差距

兩個音相差幾個半音，整首歌就移動幾個半音。

4

選擇指型與 Capo

挑選最順手的開放和弦指型，再以 Capo 補足差距。

轉01:05–01:40　第八章、詞曲創作概論

寫歌，從一個故事開始

主題與故事

人物、事件、時間、地點、物件：主角是誰、發生什麼事、何時、何地、留下什麼。越具體越動人。

人稱立場

以「我」敘述自己的故事，或以「他」敘述別人的故事。人稱決定聽眾所站的位置。

押韻

句尾使用同韻的字（例如ㄡ韻：行走、雙手、長久），歌詞就順口好記。可以一韻到底，也可以段落換韻。

曲式

主歌敘述故事、副歌說出重點。第六章畫過的曲式地圖，也能當作寫歌的架構。

記錄保存

靈感來得快、去得也快，隨時用手機錄音或備忘錄記錄下來。

修正回饋

寫完先擱置一天，再唱給朋友聆聽，逐句修改。多數好歌都經過反覆修改。

找出句尾押同一個韻的組合

選出一韻到底的那一組

  1. 天空、海洋、星星
  2. 放手、以後、溫柔
  3. 思念、遠方、季節

「放手、以後、溫柔」的句尾都是ㄡ韻。押韻可以每句押，也可以只在段落的句尾押，後者聽起來最順口。

民謠吉他弦的種類

磷青銅：溫暖、耐用，最常見。80/20 黃銅：明亮，聲音較快變暗。鍍膜弦：手感滑順、壽命較長，價格較高。
