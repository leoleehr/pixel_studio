你的期末作品準備到哪裡了？

  • 調音後，每人用 30 秒彈期末作品的副歌

期末作品可以是：彈唱一首喜歡的歌、改編一首歌，或自己寫的歌。今天的內容會幫你把它調整到最舒服的樣子。

副歌的高音唱不上去，最好的辦法是？

選出最好的解決方式

  1. 用力喊上去
  2. 換一首歌
  3. 把整首歌移到低一點的調
  4. 高音那句不要唱
原調是為原唱者設計的。把整首歌一起降低，旋律與和弦的關係不變，只是更適合你的嗓子。這就是「移調」。

承00:20–00:55　第六章、轉調與移調 Transpose

移調：每個和弦移動一樣的距離

原調 CCGAmFEmDm
升 2 個半音 → DDABmGF#mEm
降 3 個半音 → AAEF#mDC#mBm
用級數看IVviIViiiii

兩種方法

① 換和弦：每個和弦都移動相同的半音數。② 用 Capo：指型不變，夾高幾格就升幾個半音。

級數最好用

記得歌是 I–V–vi–IV，換到哪個調都能馬上排出和弦。

互動選擇題
承小測驗

移調練習

G → D → Em → C 移到 C 調（降 7 個半音，或升 5 個半音）是？

  1. C → F → Dm → Bb
  2. C → G → Am → F
  3. C → G → Em → F
  4. A → E → F#m → D
G 調的 I–V–vi–IV，換到 C 調還是 I–V–vi–IV：C → G → Am → F。

歌是 E 調，你想用 C 指型，Capo 要夾幾格？

  1. 第 4 格
  2. 第 3 格
  3. 第 5 格
  4. 不用夾
C → C# → D → D# → E，四個半音，夾第 4 格。也可以改用 G 指型夾第 9 格，但太高了。
承二、歌曲定調之方法 Make Your Own Key

四步驟，算出你的調

1

找歌的最高音

通常在副歌，對照原唱或譜。

2

測自己的最高音

能輕鬆唱、不用喊的最高音，不是極限音。

3

算差距

兩個音差幾個半音，整首歌就移幾個半音。

4

選指型＋Capo

挑最好彈的開放和弦指型，用 Capo 補足。

轉01:05–01:40　第八章、詞曲創作概論

寫歌，從一個故事開始

主題與故事

人、事、時、地、物：誰、發生什麼、什麼時候、在哪裡、留下什麼。越具體越動人。

人稱立場

用「我」說自己的故事，或用「他」說別人的故事。人稱決定聽眾站在哪裡。

押韻

句尾用同韻的字（例如ㄡ：走、手、久），歌詞就順口好記。可以一韻到底，也可以段落換韻。

曲式

主歌說故事、副歌說重點。第六章的地圖，就是寫歌的藍圖。

記錄保存

靈感來得快去得快，手機錄音、備忘錄隨時記下來。

修正回饋

寫完先放一天，再唱給朋友聽，一句一句修。好歌都是改出來的。

互動選擇題
轉押韻練習

哪一組句尾押同一個韻？

選出一韻到底的那一組

  1. 天空、海洋、星星
  2. 放手、以後、溫柔
  3. 思念、遠方、季節
  4. 回憶、離開、雨天
「手、後、柔」都是ㄡ韻。押韻不用每句都押，但段落的句尾押韻，聽起來最順。

常用韻腳

ㄚ：她、話、家、花
ㄢ：天、邊、遠、念
ㄤ：光、方、唱、想
ㄡ：走、手、久、後
ㄧ：你、起、心、記

合參考區：第十二章、木吉他保養與實務

讓吉他陪你很久

部位保養方式
指板換弦時擦乾淨；玫瑰木、黑檀木指板一年上一兩次指板油
琴身彈完用乾布擦掉手汗；避免日曬、高溫、潮濕
琴弦彈完擦弦；聲音變悶、生鏽就該換，常彈的人約一到兩個月換一次
環境濕度約 45–55%，台灣夏天放除濕包或防潮箱

民謠吉他弦的種類

磷青銅：溫暖、耐用，最常見。80/20 黃銅：明亮，但較快變暗。鍍膜弦：手感滑、壽命長，價格較高。

換弦步驟

一次換一條 → 弦釘固定弦尾 → 留兩三格長度繞旋鈕 → 往同一方向捲 → 調音、拉一拉弦再調一次。
