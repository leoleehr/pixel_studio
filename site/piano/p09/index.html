G 大調

G　→　C　→　D　→　G

和弦名稱完全不同，但在各自的調裡，都是第 1 級 → 第 4 級 → 第 5 級 → 第 1 級。記住級數，就能在任何一個調彈奏同一首歌。

以羅馬數字，記錄和弦在調裡的位置

級數ⅠⅡmⅢmⅣⅤⅥmⅦdim
C 大調CDmEmFGAmBdim
G 大調GAmBmCDEmF♯dim
F 大調FGmAmB♭CDmEdim
D 大調DEmF♯mGABmC♯dim

每一個大調的順階和弦，性質都相同：Ⅰ、Ⅳ、Ⅴ 是大和弦，Ⅱ、Ⅲ、Ⅵ 是小和弦，Ⅶ 是減和弦。

承和弦的家族與功能

主和弦是家，下屬和弦出門，屬和弦想回家

T

主和弦 Ⅰ

安定、結束。Ⅵm、Ⅲm 與它共用兩個音，可以代替主和弦。

S

下屬和弦 Ⅳ

離開家，製造流動；Ⅱm 與它相似，常放在屬和弦之前。

D

屬和弦 Ⅴ

充滿張力，最想回到主和弦；Ⅶdim 也有相同的傾向。

Ⅰ、Ⅳ、Ⅴ 合稱「主要三和弦」，音階的七個音，都包含在這三個和弦裡。許多民謠與兒歌，只用這三個和弦就能完成。

級數與功能

G 大調的 Ⅴ 級和弦是？

  1. G
  2. C
  3. Em
  4. D
G A B C D：第 5 個音是 D，所以 Ⅴ 級是 D 和弦。

哪一個和弦最常用來代替 C 大調的主和弦？

  1. Am
  2. F
  3. G
  4. Bdim
Am（A C E）與 C（C E G）共用 C 與 E，屬於主和弦的家族。
