承00:20–00:55　分散和弦伴奏法

指位譜：用手指的位置，寫下伴奏

  • L 是左手、R 是右手，數字是手指編號
  • 左手 L5 L3 L2 L1 彈奏根音、三音、五音、高八度根音
  • 右手 R1 R2 R5 接著往上：三音、五音、根音
  • 換和弦時，手指的位置不變，整隻手移到新的根音
承節奏型態（一）Slow Soul

Slow Soul：時下流行歌曲最常見的節奏

型態簡譜（C 和弦）指位特色
（一）1̣ 5̣ 1 3 5 －L5 L2 L1 R1 R2上行之後延長，留白給旋律
（二）1̣ 5̣ 1 3 5 1̇ 5 3L5 L2 L1 R1 R2 R5 R2 R1上行再下行，八分音符流動
（三）（1 3 5）× 4L5＋L3＋L2柱式和弦，穩定有力
（四）1̣ 5̣ 1 5̣ 3 5̣ 1 5̣L5 L2 L1 L2 R1 L2 L1 L2五音像鐘擺，來回擺動

四種型態可以混合使用：主歌用（一）留空間，副歌換成（二）或（四）推高情緒。

轉伴奏觀念

迷思還是事實？

伴奏的音越多，聽起來越好
迷思伴奏太滿會蓋過旋律與歌聲，留白也是一種技巧。
換和弦時，伴奏型的手指位置不變
事實整隻手平移到新的根音，指位譜照樣彈奏。
三拍子的歌一定很慢
迷思拍號和速度沒有關聯，快速的圓舞曲也很常見。
左手彈伴奏時要比右手小聲
事實旋律是主角，伴奏是舞台；左手輕一點，旋律才會浮出來。
踏板要等到全部學會才能使用
迷思分散和弦搭配延音踏板最好聽，換和弦時記得換踏板。
同一首歌只能用一種伴奏
迷思主歌、副歌換用不同的伴奏型，是流行鋼琴常見的做法。
